A desktop application for generating short-form videos and preparing them for TikTok publication.

About the application

Cursed TikTok Bot is a Windows desktop application that helps creators generate short-form vertical videos from locally supplied video material. The application can randomly select source clips, apply transformations, assemble the result, and prepare the final video for publication.

How it works

  1. The user supplies video files to the application.
  2. The application generates a short-form vertical video locally on the user's computer.
  3. The user can authorize the application to interact with their TikTok account through TikTok's official APIs.
  4. When authorized and configured, the application can prepare and publish generated content to TikTok according to TikTok's available permissions and review requirements.

Data and permissions

The application is designed to use TikTok authorization only for functions explicitly enabled by the user. TikTok account authorization is handled through TikTok's official authorization flow. The application does not sell user data.
