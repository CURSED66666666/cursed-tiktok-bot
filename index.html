Cursed Video Bot

A desktop application for creating short-form vertical videos from user-provided video material and, when authorized, preparing or publishing that content through TikTok's official developer APIs.

Desktop applicationShort-form videoTikTok integration

What Cursed Video Bot does

The application is designed for creators who want to turn their own source material into short-form videos through a repeatable local workflow.

Generate

Select local source videos and assemble short-form vertical content using automated video-processing steps.

Prepare

Produce a final video file that can be reviewed before it is shared to a connected TikTok account.

Publish

When the user has authorized the integration and the required TikTok permissions are available, the application can use TikTok's official APIs for supported publishing actions.

How it works

Provide source material

The user selects video files that they are entitled to use. Source material is processed locally by the desktop application.

Create the video

The application selects and processes source clips and assembles a short-form vertical video.

Connect TikTok

The user can authorize the application through TikTok's official authorization flow. The application requests only the permissions configured for its enabled TikTok features.

Review and publish

The user can review the generated result. If the relevant TikTok integration and permissions are available, the application can send the content through the supported TikTok publishing API.

TikTok integration

Cursed Video Bot does not represent itself as TikTok and does not replace TikTok's own authorization or account systems. TikTok account authorization is handled through TikTok's official developer infrastructure. Use of TikTok remains subject to TikTok's terms, policies, and technical requirements.

Publishing capabilities depend on the products, scopes, account status, and review status enabled for the application.

Privacy and user control

Local video processing

Video source files and generated files are intended to remain under the user's control on the computer where the desktop application runs, unless a user explicitly enables a service that requires transmission.

Authorization

TikTok authorization is performed through TikTok's official OAuth flow. Authorization data is used only to operate the enabled integration.

User responsibility

Users are responsible for the rights to their source material and for reviewing content before publication.

Before publishing

Always review generated content and confirm that you have the necessary rights and permissions before publishing it. TikTok API availability and publishing restrictions may change over time.
